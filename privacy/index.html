02 // client_storage

Functional Local Storage

We do not store cookies on your device. We use your browser's standard localStorage strictly for essential functional preferences requested by you:

• theme: Remembers your dark mode / light mode selection.
• lang: Remembers your preferred display language (EN / NL).
• ratelslop_repos_cache_v5 and ratelslop_repos_cache_time_v5: Store public GitHub repository information, including programming languages and configured website URLs, and its timestamp locally. Cached data is reused for up to 5 minutes to avoid GitHub API rate limits; the stored values remain until replaced or cleared from your browser.

This data stays exclusively on your own device and is never transmitted to us or third parties. Under the EU ePrivacy Directive, the Dutch Telecommunications Act (art. 11.7a), and the German TDDDG (§ 25 Abs. 2 Nr. 2), strictly functional storage requested by the user does not require a cookie banner.

03 // infrastructure

Hosting & Server Logs

This website is statically hosted via GitHub Pages (operated by GitHub Inc. / Microsoft Corporation, certified under the EU-U.S. Data Privacy Framework). When you visit any page, the hosting infrastructure automatically processes technical connection data (such as your IP address, browser user-agent, and request timestamps) in transient server access logs to deliver web pages securely and defend against denial-of-service (DDoS) attacks.

Legal Basis & Retention Period: The legal basis for this technical logging by our hosting provider is legitimate interest (Article 6(1)(f) GDPR / DSGVO) to ensure network stability, system resilience, security diagnostics, and DDoS mitigation. Server access logs are retained by GitHub in accordance with their own infrastructure and data retention policies, over which we as developers have no control or access; please refer to the GitHub Privacy Statement for current details.

04 // external_services

External Links, GitHub API & Project Hosting

Direct GitHub API Calls: When you browse this site, your web browser executes direct client-side HTTP requests (fetch) to the public GitHub API (api.github.com) to retrieve our public repository list, configured website URLs, and the programming languages of each displayed repository. Cached results are reused for 5 minutes. This means your IP address and technical browser metadata are transmitted directly from your device to GitHub Inc. (USA). The legal basis is our legitimate interest (Article 6(1)(f) GDPR / DSGVO) in displaying an up-to-date project overview. This dynamic third-party data stream operates directly between your browser and GitHub, governed by the GitHub Privacy Statement (certified under the EU-U.S. Data Privacy Framework).

Showcased Projects & Independent External Hosting: While public repositories belonging to our GitHub organization are dynamically displayed on this central hub, the tools, applications, and live demos themselves are not necessarily hosted on ratelslop.studio. Individual contributors within the collective independently maintain and host their own projects on various infrastructure providers (such as Cloudflare Pages/Workers under external domains including, but not limited to, schoolnaam.nl, ratelslop.studio, and hooijmaijers.me). Clicking on project demo links navigates you away from this hub to external infrastructure. We do not manage, control, or assume responsibility for data processing on such external services; please consult the privacy policy and hosting documentation of the respective external project or domain.

05 // compliance

Your Rights (GDPR / AVG / DSGVO) & Contact

Data Processing Distinction: We, the independent developers behind RatelSlop, do not collect, store, or process any personal data, user accounts, mailing lists, or profiling databases. Technical connection data (such as IP addresses and server access logs) is processed exclusively at the infrastructure level by our hosting provider GitHub Pages for secure web delivery (see Section 03). We do not possess, store, or inspect identifying user records.

Direct Contact: For privacy questions, data subject inquiries, or responsible disclosure, you can reach the maintainers directly via email at support@ratelslop.studio or via our GitHub organization (github.com/RatelSlop).

Right to Lodge a Complaint (Art. 77 GDPR): If you believe that our handling of personal data violates the General Data Protection Regulation (GDPR / DSGVO), you have the right to lodge a complaint with a competent supervisory authority. In the Netherlands, this is the Autoriteit Persoonsgegevens (AP) (autoriteitpersoonsgegevens.nl); in Germany, this is the competent Landesdatenschutzbehörde of the respective federal state.
